# Projeto 04 — Cobertura de Testes com IA

> Leve um módulo com baixa cobertura de testes a 80%+ usando Claude Code e Copilot para identificar e gerar os casos ausentes.

---

## Sobre o Projeto

Você recebe um serviço de processamento de pagamentos funcional com apenas 28% de cobertura de testes. Sua missão é usar IA para identificar os gaps de cobertura, priorizar o que testar e gerar os testes faltantes — atingindo 80% de cobertura de linhas.

## O que você vai praticar

- Usar o relatório de cobertura como guia para o que pedir ao agente
- Distinguir testes que têm valor real dos que apenas aumentam a métrica
- Usar `@test-expert` e Claude Code para gerar testes de qualidade
- Avaliar criticamente os testes gerados antes de aceitar
