# Projeto 03 — Refatoração de Código Legado

> Refatore um módulo de código legado mal estruturado usando um fluxo de agente, sem quebrar o comportamento existente.

---

## Sobre o Projeto

Você recebe um módulo de processamento de pedidos com código real de produção legado: lógica duplicada, funções com múltiplas responsabilidades, sem testes, acoplamento excessivo e nomes de variáveis crípticos.

Sua missão é refatorar o módulo usando Claude Code e Copilot de forma incremental — mantendo o comportamento original verificado por testes que você vai escrever **antes** de refatorar.

## O que você vai praticar

- Escrever testes de caracterização antes de refatorar (técnica de Michael Feathers)
- Usar Claude Code para planejar e executar refatoração incremental
- Usar Copilot Chat para entender código legado rapidamente
- Validar que o comportamento não mudou após cada passo

## Técnica Central: Refatoração Segura com IA

```
1. Entender o comportamento atual (sem alterar o código)
2. Escrever testes que documentam o comportamento existente
3. Refatorar com confiança — os testes "travam" o comportamento
4. Melhorar a estrutura sem mudar o que o código faz
```
